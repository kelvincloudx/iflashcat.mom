在诸多基于开源路由核心的图形界面中，ClashParty 凭借轻量化的资源占用和清晰现代的界面排版，成为不少追求极简操作体验用户的首选工具。对于使用闪电猫（SpeedCAT）服务的用户来说，掌握在 ClashParty 中如何正确导入订阅、设置规则以及按需切换节点，能极大提升日常上网的便捷度。本文将围绕 ClashParty 的可核实通用功能，提供一份详尽实用的操作指引。

## 一、ClashParty 基础特性与运行环境

ClashParty 是一款封装了成熟路由内核的轻量级桌面客户端，旨在简化常规网络配置流程。其核心功能包括订阅源解析、分流规则路由、节点延迟批量测速以及实时流量状态监测。

在安装与运行该工具前，请确认您的系统满足基础环境要求：
- **操作系统版本**：支持 Windows 10（64位）及 Windows 11 主流正式发行版本。
- **系统依赖库**：需确保系统已安装 Microsoft Visual C++ 2015–2022 Redistributable 运行库及 WebView2 运行时环境，以便前端窗口正常渲染。
- **权限管理**：初次启动建议使用管理员身份运行，以确保写入系统代理注册表及调用虚拟网卡适配器的权限完整。

## 二、在 ClashParty 中导入闪电猫订阅

闪电猫为用户提供了标准通用的订阅链接格式，在 ClashParty 中的导入过程非常直观：

1. **准备订阅链接**：首先前往订阅服务平台复制已购套餐的专属链接。若您还在挑选合适的流量方案，建议先查阅 [闪电猫 SpeedCAT 套餐价格与选购全解析](/guides/speedcat-plans/)。
2. **打开订阅配置页面**：在 ClashParty 主界面的左侧导航栏中，点击进入「Profiles（配置文件 / 订阅）」选项卡。
3. **添加新配置**：点击界面右上角或列表下方的「Add Profile / New」按钮，选择「Remote URL（远程链接导入）」方式。
4. **填入必要参数**：
   - **Name（配置备注）**：输入自定义名称，例如 `SpeedCAT-Main`。
   - **URL（订阅地址）**：将复制的订阅链接完整粘贴至输入框，注意去除前后可能误复制的空格。
   - **Update Interval（自动更新周期）**：建议设置为 24 小时或 1440 分钟，使客户端能定期拉取最新的服务节点。
5. **下载与保存**：点击「Save / Download」，ClashParty 将自动发起 HTTPS 握手并拉取节点清单。成功下载后，点击该配置卡片将其设置为当前激活项（Active）。

## 三、节点切换与策略组管理

导入成功后，切换至 ClashParty 的「Proxies（代理节点）」页面，您将看到结构化的节点管理视窗：

### 1. 批量延迟测速
点击顶部工具栏的测速图标（通常为闪电或信号波纹图标），客户端会并发向测试服务器发送检测包并返回毫秒（ms）延迟。
- 绿色或低数值（< 80ms）：通常为中国香港、日本或新加坡线路，适合日常高速冲浪。
- 黄色或中等数值（100ms–200ms）：通常为美西、欧洲等远距离线路，适合跨境数据传输。
- 超时或红色标红：可能当前网络链路出现抖动或节点处于短时维护，建议切换至其他可用节点。关于各区域节点的网络特征，欢迎参阅 [闪电猫节点使用指南：延迟与线路选择](/guides/speedcat-nodes/)。

### 2. 节点选择机制
在「Proxy / 节点选择」策略组中，您可以手动点击指定的节点卡片进行锁定；若启用了「Auto / 自动测速选择」，客户端则会根据定时测试结果自动引导流量走向延迟最低的健康节点。

## 四、规则模式（Rule）的深度应用

为避免不必要的流量消耗，强烈建议将 ClashParty 的模式保持为「Rule（规则模式）」：
- **智能分流机制**：当您访问国内主流电商、支付或本地新闻应用时，数据包将直接走本地宽带直连，不仅访问极速，而且不会消耗闪电猫套餐的宝贵流量配额。想要合理规划套餐流量，可参阅 [闪电猫套餐流量计算与使用说明](/guides/speedcat-data/)。
- **海外分流机制**：当访问受限或国际站点时，流量自动通过已选中的闪电猫优质节点中转。
- **模式误选提醒**：如果误切为「Direct（直连）」，则代理不会发挥任何效果；如果误切为「Global（全局）」，则本地所有网络请求均会经过节点，容易造成国内软件定位异常甚至加速套餐流量的无谓耗尽。

## 五、订阅维护与故障快速处理

1. **手动更新订阅**：当发现部分节点长时间无法连通或列表变空时，回到「Profiles」面板，点击配置卡片上的「Update（刷新）」按钮，重新下载远程最新配置。
2. **重置系统代理**：若因异常关机导致网页无法打开，检查 ClashParty 的「System Proxy」开关，先关闭再重新开启即可重置 Windows 注册表代理项。
3. **深入排查连接问题**：若排查上述步骤后依旧报错，请参考 [闪电猫常见连接问题与排查教程](/guides/speedcat-troubleshooting/)，按标准步骤快速恢复连接。
