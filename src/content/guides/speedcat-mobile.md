随着移动办公与智能手机的全面普及，在手机端使用加速网络已成为多数用户的刚需场景。相比桌面计算机，智能手机具有经常在移动蜂窝网络（4G/5G）与家庭 Wi-Fi 之间自由切换、且系统后台具备严苛的省电与墓碑机制等特性。本文将面向 Android 与 iOS 平台用户，详细讲解如何安全、规范地配置闪电猫（SpeedCAT）网络订阅。

## 一、Android 平台客户端选择与安全安装

Android 系统由于具备开放的 APK 侧载能力，用户在获取客户端时更需要严把安全关口：

### 1. 客户端选型原则
建议选用社区广泛维护、经过安全审计的主流通用开源工具（如 Clash Meta for Android、NekoBox for Android 等）。这类应用兼容标准的 YAML 订阅及通用链接协议，路由分流机制成熟。

### 2. 安全安装渠道
- **官方开源仓库**：优先通过开发团队在 GitHub Releases 发布的经过签名认证的正式 APK 文件进行下载。
- **正规应用商店**：通过 Google Play 商店安装经过平台安全扫描的版本。
- **杜绝来路不明的修改版**：绝对不要从不明网站下载宣称“内购破解”或“免流”的 APK 包，此类应用常带有广告注入、后台私开代理端口乃至个人隐私泄露的严重隐患。

## 二、iOS 平台客户端获取途径与生态环境

iOS 系统实行严格的应用沙盒管理机制，其客户端安装具有独特性：

1. **海外 Apple ID 准备**：由于国内 App Store 的监管政策，网络代理类应用未在国区上架。用户需自行注册或持有受支持的非中国大陆地区 Apple ID（如美区、日区等）。
2. **正规安装通用工具**：在切换为海外 Apple ID 后，前往 App Store 搜索并下载主流通用代理工具（如 Shadowrocket、Loon、Quantumult X 等）。请注意支持正版开发，切勿轻信所谓的“免费共享证书”。
3. **权限授权**：初次启动工具时，系统会弹出“添加 VPN 配置”的提示，需输入手机解锁密码完成授权，以便工具在系统底层建立虚拟网络适配器通道。

## 三、手机端订阅导入与连接步骤

移动端导入闪电猫订阅流程非常简洁明快：

1. **复制订阅地址**：在手机浏览器登录您的服务管理中心，完整复制属于您的个人订阅 URL（如尚未选定套餐，可前往查看 [闪电猫六种套餐价格与选购指南](/guides/speedcat-plans/)）。
2. **在客户端内添加订阅**：
   - 打开工具的配置/订阅管理界面，点击右上角的「+」或「添加配置」按钮。
   - 协议类型通常选择「URL / 远程下载」。
   - 粘贴订阅地址，并填写易于识别的名称（如 `SpeedCAT`）。
3. **完成配置下载**：点击保存或拉取，客户端将向远程服务器请求配置文件，成功后即可在节点列表中看到完整的节点群组。
4. **启动代理连接**：选择延迟较低的地区节点（如香港、日本节点），将代理模式设为「配置 / 规则（Rule）」，最后打开总开关即可启动。各节点特性可查阅 [闪电猫节点延迟与线路选择指南](/guides/speedcat-nodes/)。

## 四、移动蜂窝网络与 Wi-Fi 切换时的注意事项

手机在日常通勤与室内场景频繁切换网络连接，需注意以下底层现象：

- **网络切换短暂瞬断**：当手机从 Wi-Fi 断开转入 5G 移动蜂窝网络时，手机的本地 IP 和网关会发生重置，此时 TCP 连接需重新建立握手，属于正常物理切换现象。通常等待 2–3 秒即可自动恢复。
- **蜂窝网络 IPv6 适配**：部分国内运营商在 5G 模式下默认分配 IPv6 地址，若客户端配置未开启 IPv6 处理，可能导致部分应用访问缓慢。可在客户端高级设置中视情况开启或关闭 IPv6 路由转发。

## 五、手机后台保活与电池省电策略设置

现代智能手机系统（如 MIUI/HyperOS、ColorOS、OriginOS、HarmonyOS 等）具有激进的后台杀进程机制，若不进行设置，常导致锁屏后代理断开：

1. **锁定后台任务卡片**：在手机多任务管理页面，长按或下拉客户端卡片，将其锁定在后台，防止被一键清理。
2. **解除电池优化**：进入系统「设置 → 应用管理 → 特殊应用权限 → 电池优化」，将代理客户端设置为「无限制」或「不优化」。
3. **自启动与常驻通知**：开启该应用的「允许后台自启动」权限，并在应用内勾选「通知栏常驻」，使系统识别其为高优先级前台服务。

若在手机端遇到无法拉取订阅或节点全超时的状况，请及时参考 [闪电猫常见连接问题与故障排查](/guides/speedcat-troubleshooting/) 进行逐项检验。
